# Project instructions

This project supports a classroom demonstration with simulated turnout data. Read `specification.md` and `data/codebook.md` to understand the analysis.

The classroom work uses `demo/cleaning.R` and `demo/models.R`. Run `Rscript --vanilla demo/run.R` from the project folder to produce the results. The analysis uses packages included with R.

Keep the raw data, analysis plan, and completed examples in `R/` unchanged. Explain any research choice that needs the instructor's decision.

Show the code changes and the resulting table and figure. Describe the results as associations in simulated data. Leave the changes for the instructor to review, commit, and, if requested, sync with GitHub.

The formal tests and the original `run.R` are available for additional checking after class. They are not required steps in the classroom demonstration. The optional API example is separate from the agent task.
